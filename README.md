# SilverEV

Две языковые версии одного статического сайта:

| Язык | Домен | Исходники | Готовый сайт |
| --- | --- | --- | --- |
| Русский | https://silverev.ru | `src/ru/` | `dist/ru/` |
| English | https://silverev.org | `src/en/` | `dist/en/` |

Общие шаблоны, стили, JavaScript и изображения находятся в `src/shared/`. Python используется только для сборки. На хостинге нужны обычные HTML-файлы: Python, SSI и дополнительные пакеты не требуются.

## Собрать и загрузить

Нужен Python 3.9 или новее, установка через `pip` не требуется. Из папки репозитория:

```sh
git pull --ff-only
python3 build.py
```

На Windows вместо `python3` можно использовать `py -3`.

После успешной сборки:

1. Загрузите **содержимое** `dist/ru/` в корень сайта `silverev.ru`.
2. Загрузите **содержимое** `dist/en/` в корень сайта `silverev.org`.

В корне каждого сайта должны лежать `index.html`, остальные страницы, папка `assets/`, `robots.txt`, `sitemap.xml` и файлы иконок. Папки `ru` и `en` на сервер переносить целиком не нужно: адреса страниц остаются вида `/news.html`, без языкового префикса. Корень репозитория и `src/` не являются готовым сайтом. `dist/` создаётся заново при сборке и не хранится в Git.

При обновлении удаляйте с сервера старые файлы сайта, которых больше нет в соответствующей сборке. Сохраните настройки хостинга и служебные файлы, не относящиеся к сайту.

Для обоих доменов настройте HTTPS и стартовую страницу `index.html`. В панели хостинга назначьте `/404.html` страницей ошибки с HTTP-статусом **404**: наличие файла само по себе не настраивает этот статус. Перенаправления с HTTP и с альтернативного имени домена должны вести на соответствующий основной HTTPS-домен.

Каждая версия имеет собственные `canonical`, `robots.txt`, sitemap и manifest. `hreflang` связывает соответствующие страницы двух доменов; `x-default` указывает на английскую версию. Переключатель RU / EN открывает ту же статью на другом языке. Ошибка 404 исключена из sitemap и помечена `noindex`.

## Предпросмотр

После сборки запустите нужную версию локально:

```sh
python3 -m http.server 8000 --directory dist/ru
```

Русский сайт откроется на http://localhost:8000. Для английского сайта во втором терминале:

```sh
python3 -m http.server 8001 --directory dist/en
```

Английский сайт откроется на http://localhost:8001. Языковой переключатель при локальном просмотре ведёт на настоящие домены.

## Редактирование

- Текст страниц: `src/ru/*.html` и `src/en/*.html`. В файлах находится только блок `<main>`.
- Заголовки для поиска, описания и принадлежность разделу: `pages.json` в каждой языковой папке.
- Навигация, подписи и сообщения об ошибках: `locale.json` в каждой языковой папке.
- Общая оболочка страниц, шапка и подвал: `src/shared/templates/`.
- Стили и скрипты: `src/shared/assets/`.
- Иконки и другие файлы, копируемые в корень обоих сайтов: `src/shared/static/`.
- Домены, контактный адрес и включение аналитики: `site.config.json`.

При добавлении страницы создайте файлы с одинаковым именем в обеих языковых папках и добавьте записи в оба `pages.json`. Переведите `title`, `description` и `og_title`; структурные поля `section`, `body_class`, `type`, `scripts` и `noindex` должны совпадать. Сохраняйте одинаковые идентификаторы разделов и ссылки на источники. Внутренние ссылки пишите от корня, например `/news.html` или `/ev-silver-demand.html#calculator`.

### Синхронизация перевода

Английская запись `source_sha256` фиксирует проверенную версию русского текста и его метаданных. При изменении русского материала сборка остановится, пока английский перевод не будет обновлён и проверен.

Посмотреть состояние переводов:

```sh
python3 tools/translations.py status
```

После редактирования и проверки английского текста подтвердите конкретную страницу:

```sh
python3 tools/translations.py mark-reviewed ev-silver-demand.html
python3 build.py
```

Команда `mark-reviewed` только записывает контрольную сумму, сама текст не переводит. Для новой страницы она также добавит `source_sha256`. Изменения общих шаблонов и `locale.json` проверяйте сразу на обоих языках: контрольные суммы относятся к отдельным страницам и их метаданным.

### Аналитика и контакты

На русском сайте сохранён существующий счётчик Яндекс Метрики. На английском аналитика выключена (`sites.en.analytics: false`), чтобы не отправлять посещения нового домена в прежний счётчик без настройки. Параметр `analytics: true` подключает общий существующий код из `yandex-metrika-*.html`; для отдельного счётчика `.org` потребуется добавить отдельную настройку и шаблон.

На обоих сайтах используется существующий адрес `contact@silverev.ru`. Его можно изменить через `contact_email` в `site.config.json` после создания нужного почтового ящика.

## Проверки

Каждая сборка проверяет внутренние ссылки и якоря, уникальность HTML ID, языки, заголовки H1, `canonical`, `hreflang`, sitemap и актуальность переводов. Непрошедшая проверку сборка не заменяет существующую папку `dist/`.

Проверить сборку без замены `dist/`:

```sh
python3 build.py --check
```

Проверить структуру переводов и поведение сборки:

```sh
python3 -m unittest discover -s tests -v
```

Проверить расчёты, граничные значения, валидацию и локализацию калькулятора (для этого теста нужен Node.js):

```sh
node tests/calculator.test.js
```
